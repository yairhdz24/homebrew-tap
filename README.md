# Homebrew tap de Yair Hernández

Apps de [yairhdz24](https://github.com/yairhdz24) para instalar con [Homebrew](https://brew.sh).

## Bruma

[Bruma](https://github.com/yairhdz24/bruma) es un teclado por voz gratis y de código abierto para Mac: toca <kbd>fn</kbd>, habla, y el texto aparece en cualquier app.

```sh
brew install --cask yairhdz24/tap/bruma
```

Actualizar: `brew upgrade --cask bruma`. Desinstalar: `brew uninstall --cask bruma` (agrega `--zap` para borrar también tus ajustes).

Requiere una Mac con Apple Silicon y macOS 12 o superior.

---

**English:** `brew install --cask yairhdz24/tap/bruma` installs [Bruma](https://github.com/yairhdz24/bruma), a free, open-source voice keyboard for macOS. The cask is updated automatically a few hours after each release.
